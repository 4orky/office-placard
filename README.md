A one-line museum placard for an ordinary office object, written as if it were an ancient artifact dug from a lost civilisation. The program writes one line to `/output/entry.txt`:

> Votive Tablet (Sticky Note), c. 2011. Paper, weak adhesive. Inscribed 'call Dave back'. The god Dave never answered. Excavated from the south monitor, still stuck.

Twelve original candidates were drafted against the judge's brief, hand-scored on invention, dryness, placard voice, economy and label craft, and the winner went through a real second pass — the semicolon splice was split so the god's silence lands as its own beat, and "still stuck" was added so the weak adhesive pays off at the end. See `main.py` for the full scoring table and revision notes.

## Run it

```sh
python3 main.py
```
